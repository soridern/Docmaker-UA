## ✨ Про проект

**DocMaker.UA** — це простий і швидкий генератор документів для ФОПів України. Жодної реєстрації, жодних API ключів, жодного інтернету не потрібно після завантаження.

### 🎯 Кому це потрібно:

| 👤 | Аудиторія |
|---|---|
| 👷 | ФОПи будівельної сфери |
| 💻 | IT-фрілансери |
| 💇 | Майстри краси та послуг |
| 🏠 | Рієлтори |
| 🚚 | Перевізники та кур'єри |
| 📋 | Всі ФОПи, які працюють з клієнтами |

<br>

## 🚀 Як користуватися

```
Крок 1 — Оберіть категорію документа
Крок 2 — Оберіть тип документа
Крок 3 — Заповніть форму
Крок 4 — Отримайте готовий документ
Крок 5 — Роздрукуйте або скопіюйте
```

**Усе! Жодної реєстрації. Жодних смс. Жодних API ключів.**
